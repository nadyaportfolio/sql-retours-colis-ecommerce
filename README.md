# Analyse des remboursements e-commerce

**Outil** : SQL · **Projet 5** · Regaload

**Objectif** : identifier les causes de remboursement, pour limiter certains retours et en valoriser d'autres.

**Démarche**
- Création d'une base de données relationnelle (schéma, dictionnaire de données)
- Requêtes SQL pour produire les indicateurs métier
- 5 règles RGPD appliquées aux données clients

**Résultats**
- 1er motif : la rétractation (931 k€), dont 91 % sur 3 catégories (informatique, téléphonie, jeux vidéo)
- DPD a le taux de non-livraison le plus élevé (2,05 %)
- Colis non réclamés : de 1 % à près de 14 % selon le transporteur

**Recommandations**
- Informer les clients avant l'achat sur les catégories les plus retournées
- Réduire les échecs de livraison avec DPD (créneaux, notifications)
- Reproduire les pratiques de Mondial Relay sur les colis non réclamés
- Scanner les produits à la préparation pour éviter les erreurs de référence
- Sécuriser la remise des colis à forte valeur
- Donner une seconde vie aux produits retournés

**Compétences** : création de base de données, requêtes SQL, RGPD
